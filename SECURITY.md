# Security policy

## Supported versions

Security fixes are applied to the latest version of the `main` branch.

## Reporting a vulnerability

Please don't report security vulnerabilities through public issues, discussions or pull requests.

Report them privately through GitHub: open the [Security tab](https://github.com/Yvngval/Predictive-Maintenance-Explainable-ML-/security) of this repository and click **Report a vulnerability**, or go straight to the [advisory form](https://github.com/Yvngval/Predictive-Maintenance-Explainable-ML-/security/advisories/new).

Please include as much of the following as you can:

- the type of issue and where it is (file, notebook, cell)
- the steps or a proof of concept to reproduce it
- the impact you think an attacker could achieve

You should get an acknowledgment within 7 days. You will be kept informed while the issue is investigated and fixed, and credited unless you prefer to stay anonymous.
